# Pokhara Wellness Hub – Personal Trainer Contact Page

A clean and simple fitness website project built with HTML, CSS, and JavaScript.  
Includes a hero section, trainer profiles, and a contact form that lets users send a message directly to the trainer via email.

## Features
- Modern hero banner with background image  
- Two trainer profiles (Tilak & Sangam)  
- Motivational quotes and trainer specialties  
- Contact form with JavaScript email trigger  
- Fully responsive layout  
- Simple and lightweight — no backend required  

## How the Contact Form Works
The **Send to Trainer** button uses JavaScript to open the user's email app with a pre‑filled message sent to:

**tilakbahadurb100@gmail.com**
